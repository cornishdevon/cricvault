Keep numbered red ball markers when refining the bowling wheel.

Each marker represents one wicket and uses its sequence number across all dismissal types, never an aggregate bowled/LBW count.

**Why:** The user rejected duplicate numbers caused by mixing individual catch numbers with a combined bowled/LBW total.

**Why:** The user explicitly liked the numbered balls after requesting balls instead of smashed-stumps graphics for bowled and LBW wickets.

**How to apply:** Preserve this visual treatment in future bowling-wheel design changes unless the user requests otherwise.
